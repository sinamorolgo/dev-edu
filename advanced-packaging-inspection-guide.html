Package anatomy

결함은 층마다 다른 얼굴을 갖습니다

광학으로 보이는 표면 결함, 금속 대비가 필요한 매몰 결함, 음향 임피던스 차이로 보이는 계면 결함, 전기 자극을 줘야 드러나는 기능 결함을 구분해야 합니다.

그림의 화살표는 “추천 장비 하나”가 아니라 품질 특성(CTQ)을 가리킵니다. 실제 장비 조합은 재료, pitch, 적층 수, X-ray 투과 경로와 takt time에 따라 바뀝니다.

Control loop

가치가 쌓이기 전에 막는 5개 게이트

최종 검사에서 모든 결함을 찾으려 하면 원인 추적도 어렵고 이미 투입된 die의 가치도 잃습니다. 공정 변수와 숨은 결함을 각각 가장 싸게 볼 수 있는 지점에 게이트를 둡니다.

적층 전

KGD, wafer sort, BIST/repair, TSV·RDL continuity, die thickness와 warpage

접합 직전

접합 직후

봉지·열처리 후

출하·수율 학습

Deep dive

예시: X-ray로 범프가 잘 붙었는가?

마이크로범프 HBM의 매몰 접합을 선별하는 핵심 수단 중 하나입니다. 그러나 “보이는 형상”과 “전기가 통하고 오래 버티는 접합”을 같은 뜻으로 쓰지 않아야 합니다.

잘 보는 것

  • missing·shifted bump와 gross misalignment
  • bridge, solder extrusion, non-wet 형상
  • solder/Cu의 큰 void·seam
  • CT/XRM에서 층별 3D 위치와 부피

놓치기 쉬운 것

  • 2D 투영에서 겹치는 다층 구조
  • FOV–해상도–scan time의 상충
  • 나노 dielectric gap·유기 오염
  • void가 없어도 생기는 high-R Cu contact

그래서 같이 보는 것

  • overlay·3D optical: 위치와 높이
  • SAM/IR: non-bond와 delamination
  • Kelvin/daisy-chain: continuity·저항
  • FIB/단면: root-cause 확인
판정: X-ray/CT로 매몰 형상과 void를 선별하고, SAM/IR로 계면을 보고, Kelvin·daisy chain으로 전기 연결을 증명합니다. 하이브리드 본딩이면 이보다 앞에 pre-bond surface와 pitch·spec에 맞춘 고정밀 overlay 계측이 더 높은 게이트가 됩니다.

Worked example

검사 계획을 만드는 예

“HBM bump를 X-ray로 검사한다”를 실제 control plan으로 바꾸려면 결함, 검출 시점, 보조 측정과 반응 계획까지 연결해야 합니다.

상황

2.5D interposer 위에 microbump HBM과 logic die를 실장한다.

  • 고가 KGD를 이미 투입
  • 다층 bump가 X-ray에서 중첩
  • mold 후 재작업이 매우 어려움

권장 gate sequence

  1. Before bond: HBM·logic KGD, interposer RDL/TSV e-test, bump height/coplanarity와 package warpage를 확인합니다.
  2. After placement: x-y-θ/shift와 edge/corner까지 local overlay를 확인합니다.
  3. After bond: 빠른 2D X-ray로 missing/bridge/gross void를 선별하고, 위험 lot은 CT/XRM로 깊이를 분리합니다.
  4. Interface + function: SAM으로 delamination/non-bond를 보고, daisy/Kelvin으로 open/short와 contact-R를 확인합니다.
  5. Reaction: 좌표를 공통 die map에 맞춰 AOI–X-ray–SAM–e-test를 상관하고, 반복 signature만 LIT/FIB/단면으로 내려가 원인을 닫습니다.
